# Prácticas de Programación Web

En estas clases trabajamos con JavaScript, HTML y CSS mediante ejemplos y ejercicios prácticos.

## Temas vistos

- **Cadenas de texto:** uso de `length`, `split()`, `substring()`, `replace()` y otros métodos.
- **Objetos:** creación, modificación de propiedades y desestructuración.
- **DOM:** uso de `getElementById()` para acceder a los elementos de una página.
- **Eventos:** prácticas con `click`, `keyup`, `focus`, `change` y `submit`.
- **Formularios:** campos obligatorios, validaciones básicas y mensajes de confirmación.
- **HTML y CSS:** estructura y estilos para formularios y páginas sencillas.

## Ejercicios realizados

- Invertir un texto y revisar si un correo tiene un solo `@`.
- Crear objetos y obtener sus datos con desestructuración.
- Mostrar en pantalla lo que se escribe en una caja de texto.
- Trabajar con botones y listas desplegables.
- Crear un formulario de cotización de computadoras.
- Elaborar un cuestionario con preguntas y alternativas.

## Archivos

Los archivos `cadenas.js`, `objetos.js` y `desestructuracion.js` contienen ejemplos de JavaScript. Los archivos `actividad1.js`, `actividad2.js`, `actividad3.html`, `actividad4.html` y sus estilos corresponden a ejercicios prácticos. Los archivos `web1.html` a `web5.html` muestran ejemplos de eventos y formularios.
